# BluLex — Content Clipping Guides by Om Dhas

Mobile-first frontend landing page for **BluLex** (beginner content-clipping ebooks by Om Dhas).

## Features
- **Pure Frontend:** Zero backend, zero database, zero external dependencies.
- **Palette & Atmosphere:** Sky blue atmosphere at top &rarr; rich brand blue through the guides &rarr; ethereal cloudy white at the bottom.
- **3D Hero Fan:** Popping 9:16 vertical reel cards with spring physics on scroll.
- **Giant Outline:** Solid pure white `BLULEX` lettering with glowing electric magenta `X`.
- **The Catalog:** 3 distinct tilted 3D ebook covers + Quick Start bonus pack.
- **Proof:** Verified lifetime earnings graph milestone card ($517.82).
